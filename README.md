# marga-house

Interior fit-out of the Marga townhouse at Pleasant Homes II, Daet — an Airbnb that should feel like a 5-star hotel and a second home for the owners.

This repo is the single source of truth shared by the owner, ChatGPT and Claude.

- `BRIEF.md` — design brief
- `DECISIONS.md` — settled decisions
- `MEASUREMENTS.md` — dimensions and their status
- `AGENTS.md` — working rules for AI assistants
- `plan/` — floor plan drawing code and PNGs (start with `plan/README.md`)
- `renders/` — approved renders only
